# Police Rental Registration and Verification System

Next.js frontend and Express/Mongoose backend for tenant, hotel, police, and superadmin workflows.

See [SETUP.md](SETUP.md) for installation, Atlas configuration, and run commands. See [DEMO_DATA.md](DEMO_DATA.md) for the reproducible synthetic data and test account setup.

Local `.env` files, generated login lists, logs, and build artifacts are excluded from Git. Configure your own Atlas connection in `backend/.env` using `backend/.env.example`, and run the seed scripts to populate a database.
